## 区间、选择与统计解释

训练设置为 2021-01-01 至 2025-01-01，实际交易日为 2021-01-04 至 2024-12-31（969 日）；验证为 2025-01-02 至 2026-10-16，末日成交笔数整行缺失，实际截至 2026-10-15（430 日）。2020 年只提供历史预热。两段分别从 100 万元现金开始，不承接训练持仓。这里的“训练”是研究比较区间，未拟合机器学习模型。验证区间已在多轮开发中查看，入选属于事后探索性选择，不是独立样本外检验。

所有方案每日调仓，前一日收盘形成信号，至少延迟一个交易日执行；按前收固定股数，以前日已知的 20 日均额限制容量，执行 T+1、整手、涨跌停和停牌约束。最多 20 个目标槽位，目标总仓位 60%，单槽 3%，现金与受阻订单使实际仓位偏离目标。价格至少 3 元，20 日均额至少 2000 万元；佣金万三、最低 5 元、滑点 5 bps、过户费率万分之 0.1、按历史切换的印花税、金额参与率 1%。净值已含模拟费用与价格滑点，显式费用表不重复扣滑点。年化系数 252，夏普采用零无风险利率。

没有将未来标签用于信号计算，但反复查看验证结果并据此选择会造成选择偏差。未作多重试验校正，未对多日重叠标签提供统计显著性认证。后续应冻结代码和参数，在未参与开发的未来区间做前向跟踪，而不是继续将本验证段称为未见样本。

## 数据与复现

原始文件为 `feathers.zip`，2020-01-02 至 2026-10-16，1643 × 5451，含 open/high/low/close/amt/num_trades/cumadj；SHA-256 为 `5766950f2a105244867b842709cf4bad890e4e11df0eebeeaa4fec42dc05803d`。未经供应商说明确认数据来源、金额单位及复权底层口径。仓库不分发行情文件；拥有同一合法数据的人可以复跑，否则只能核验公开输出与使用合成演示。

历史运行环境：Python 3.13.8、NumPy 2.2.3、pandas 2.2.3、PyArrow 26.0.0。原始运行的 manifest 中保留具体版本和代码哈希。公开导出脱敏了绝对数据路径并更新报告品牌/导航；CSV 原字节复制，公开 checksums 对应公开文件，原始 manifest/source zip 哈希单独列在 `public_export`。引擎的计算核心与历史快照逐文件比对一致。原始代码 ZIP 没有分发，哈希本身不能替代原始数据或代码文件。

`evidence/research_verification.json` 是原研究时的检查记录；`scripts/verify_examples.py` 可重新验证公开账本摘要、IC 均值和文件校验和。整理报告没有重新跑真实数据回测，没有改变历史收益。

## 边界

这些结果是日频做多研究，采用复权经济单位账户，隐含公司行动调整及分红再投资，未重建真实股份、现金到账日与分红税。历史 ST 覆盖为 0，未知状态允许进入；涨跌停使用保守估计，未提供官方逐日规则。amt 暂按元解释但供应商单位未确认，num_trades 不是成交股数。缺少真实股数容量、独立交易日历、历史行业/市值及完整退市处置数据；停滞估值未施加折扣。日线不能证明开盘流动性或排队成交。尚无真实券商联调及目标服务器验收。

日内反转研究背景可参见 [Short-Term Return Reversals and Intraday Transactions](https://doi.org/10.1142/S2010139219500022)。项目的窗口、过滤和组合设定是自己的探索性配置，不宣称复现该论文。研究流程参考 [WorldQuant BRAIN](https://www.worldquant.com/brain/)，没有官方关联或算子兼容承诺。
