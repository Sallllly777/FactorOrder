# 因序 · 网页因子研究工作台

工作台直接调用已有回测引擎与持久化任务服务，使用本地静态资源，不依赖 CDN、Node 构建环境或外部账户。参考 BRAIN 的研究流程，采用独立品牌与界面，不宣称算子或指标兼容。

## 在当前电脑启动

在项目目录的 PowerShell 中运行：

```powershell
python start_ui.py
```

浏览器自动打开 http://127.0.0.1:8000 。将终端显示的临时访问密钥复制到登录框。没有设置 `PKUQUANT_API_TOKEN` 时，启动器生成随机密钥，仅保留在当前服务进程；不会写入文件。终端请留着，按 Ctrl+C 停服。重启后重新登录，已有任务与结果仍保存在磁盘。

新环境先安装 `python -m pip install -e '.[service,test]'`。端口占用时使用 `python start_ui.py --port 8001`；不自动打开浏览器使用 `--no-browser`。数据源配置默认是 `examples/service.json`，可以通过 `--config` 指定其他配置；文件内路径相对该配置文件解析。

已安装的 wheel 也包含网页资源：通过 `pkuquant serve --service-config <配置文件>` 启动后访问根路径。该方式需事先设置 `PKUQUANT_API_TOKEN`。

## 研究流程

1. 连接服务，选择管理员登记的数据源。当前原始数据源对应 `feathers.zip`。
2. 首次打开且无草稿时载入“基础5DR · 当前保留版”：每日20只、60%目标仓位、保留排名20、价格至少3元及20日均额至少2000万元。点击该模板同时载入完整设置和验证日期；重置参数也使用该模板设置。已有草稿不自动覆盖，请主动点击模板切换。也可选择低波动、动量、反转或流动性表达式；网页只接受受限表达式，不运行任意 Python。
3. 设置区间、股票池、持仓数、调仓频率、滑点和费用。在“数据与风险约束”设置 ST 缺失处理、规则完整性与容量条件。当前5DR模板日期为2025-01-02至2026-10-16（末尾缺数据日自动剔除），通用表达式默认设置仍为2023年。更新源码后需要重启现有服务并刷新网页才能使用新目录。
4. 点击运行或 Ctrl+Enter。页面显示排队、运行、失败、取消和完成状态；计算发生在后台进程，关掉网页不会取消任务。
5. 查看净值/回撤曲线、收益风险指标、成交摘要及 Rank IC。图表与指标取自真实结果文件；曲线超过 2,500 个交易日时抽样展示，统计指标仍基于全部交易日。
6. 在“回测记录”查看最近 100 个任务，复用表达式与完整参数；导出报告、订单、净值与审计配置。策略 JSON 也可导入导出。

草稿保存在当前浏览器的 localStorage，包含表达式与参数，不含访问密钥。断开服务保留草稿；共享电脑应自行清理站点数据。历史结果展示其自己的表达式，修改编辑器不会改变已完成结果。桌面参数栏在右侧；窄屏可展开“回测设置”。

## 数据口径

原始 ZIP 缺少历史 ST 和完整官方逐日规则，界面会显示 ST 覆盖率、未知证券日数量与估计规则订单数。未知状态数量来自该次加载的数据范围，可能包含因子预热日期，不等于当期持仓数量。允许未知状态是显式研究假设；要求严格状态或规则时，原始数据可能无法通过检查或无法形成组合。

当前是 A 股日频只做多研究系统，采用复权经济单位账户与日线近似成交。前复权、信号延迟、涨跌停等执行规则由既有引擎处理。网页没有添加实盘下单能力。合成数据结果有明确标识，不作为真实市场策略证据。示例表达式未做收益优化，示例结果不是策略推荐。

## 会话与部署

API 的 Bearer 鉴权继续可用。网页登录将访问密钥交换为 8 小时 HttpOnly、SameSite=Strict 会话 Cookie；HTTPS 下设置 Secure。服务重启或退出登录会使相应会话失效。浏览器修改请求验证自定义头与 Origin，静态页面有 CSP，禁止外部脚本、内联脚本和被其他页面嵌入。

页面外壳、静态资源、公开算子目录和健康接口可匿名读取；数据源、任务及结果需要登录。所有持有密钥的人仍共享同一组任务权限。尚无个人账号、租户隔离、计费或管理员网页；当前适合本地或受控单团队私有研究服务。

未来通过反向代理部署时必须保留外部 Host，并仅信任指定代理的转发头，使请求 scheme/host 与浏览器 Origin 一致，保证 Secure Cookie 与 CSRF 检查正常工作。不要用关闭检查来修复代理配置。实际 TLS、服务器资源配额、负载与恢复仍需目标环境验收，详见 [部署手册](deployment.md)。
