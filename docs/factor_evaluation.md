# 因子评价协议 v1.1

本版本把评价接入 Python API、CLI、异步服务、网页、离线报告和可复核导出。它是研究工具，不是统计认证或实盘准入系统。当前评分为 **heuristic-1.1**，阈值未经独立样本校准。

## 使用

```python
from pkuquant import Research, Settings, EvaluationSpec

result = Research('feathers.zip').run(
    '-rank(ts_return(close, 5))',
    Settings(start='2023-01-03', end='2023-12-29', top_n=20,
             retain_n=20, rebalance='daily', gross_exposure=.6),
    evaluation=EvaluationSpec(
        stress_tests=True, family='reversal-v1', declared_trials=1,
        train_start='2023-01-03', train_end='2023-06-30',
        validation_start='2023-07-03', validation_end='2023-12-29',
        peers=('rank(ts_mean(amt, 20))',),
    ),
)
print(result.evaluation.summary['score'])
result.save('outputs/reversal-evaluated')
```

默认生成基础评价与一个流动性基线；四组压力测试默认关闭，避免原有批量回测无提示地增加大量模拟。设置 `stress_tests=True` 启用费用、延迟、资金和因果平滑场景。无同伴时增量项目未评价。`evaluation={'enabled': False}` 跳过评价，但仍尊重显式指定的 `direction`。省略评价配置时，原来的高值优先交易行为不变。

策略 JSON 顶层新增 `evaluation`，可用于 `run.py run --strategy ...`、`compare`、网页导入导出、API `/jobs`。旧 JSON 继续可用。参考 [evaluation_reversal.json](../examples/evaluation_reversal.json)。网页“回测设置 → 因子评价协议”配置，“因子评价”页审阅。切换策略模板保留评价协议，便于按共同口径比较；请主动检查方向是否与表达式一致。

## 标签和样本

- 信号日期为 t，进入价格为第 t+delay 个数据交易日的复权开盘价，退出为 t+delay+h。默认主期限 1，辅助期限 5、10、20；不得越过请求结束日。
- 价格为 `open * cumadj`，继承复权经济单位假设。未来收益只进入评价模块，不进入表达式 Fields 或模拟器。标签不包含成交失败与交易费用。
- 每个期限独立选择有限的信号及收益端点，增加长周期不减少短周期样本。无前向填充，无事后全期收益截尾。
- Top-N 使用实际 Settings.top_n，不固定成 Top20。先在当日可选且有限的信号上分组、选 Top-N，再审计未来标签缺失。Top-N 边界同分使用分数权重；分组使用平均排名，同分不按证券代码拆开。相同信号可能减少实际组数。
- Top-N 超额为其有标签成员的加权平均收益减同池有标签样本均值；小样本、常数信号或 N 覆盖全池时不评分。它不是可交易等权基线，也不等于组合净收益。
- 分别保留可选数、有限信号数、有效标签数、右端截断、内部端点缺失、Top-N 分配权重和有效标签权重。右端截断不计入成熟标签覆盖率分母。
- 默认至少 20 个横截面样本、60 个有效 IC 日期、80% 成熟标签覆盖率。未达到条件，状态为 `insufficient_evidence`，所有分项暂停评分。达到条件仍只为 `research_only`。
- 历史 `factor_diagnostics.csv` 保留原收盘到收盘口径，修正无限信号不应计入覆盖率的问题。不要将其与新开盘标签 IC 混用。

## 不确定性

对逐日 Pearson IC、Rank IC、Top-N 超额、分层相关和分层价差分别计算均值、正值日期比例、HAC 标准误和近似 95% 区间。至少 20 个有效日才计算区间。Bartlett 带宽为 `max(h-1, floor(4*(T/100)^(2/9)))`，上限 T−1；缺失日按原交易日位置保留，中心残差置零计算成对协方差，不压缩日期。HAC 不解决非随机缺失或结构突变。

默认 200 次固定种子循环区块 bootstrap，区块长度 `max(h, ceil(T^(1/3)))`，输出均值的 2.5% / 97.5% 分位数。可通过 `bootstrap_samples=0` 关闭，最多 2000 次。区间是单次试验的近似描述，不是对所有尝试的联合置信区间；界面主要展示 HAC，完整 JSON 保留两种区间。

## 对照和压力

基线表达式默认 `rank(ts_mean(amt, 20))`；基线与候选复用相同股票池、资金、费率、调仓、容量、持仓上限、状态和执行模型。信号有效日期不足的基线不当作零收益现金基线评分。

四种压力各单独改变一个方面：佣金/最低佣金/过户费/滑点翻倍（法定印花税不变）；delay+1；资金×2；候选信号额外两日因果均值平滑。每个场景保存完整 Settings。后者是信号扰动，不能证明原始数据修订、表达式参数或全部交易参数稳健。

最多三个固定同伴，同伴和基线均高值优先；候选 direction=-1 不反转同伴。输出共同有效样本内的日截面排名相关、日组合收益相关和股票持仓权重交并比。日信号绝对相关先取绝对值再按日期平均，避免正负抵消。持仓交并比为共同证券的较小权重之和除以两组合较大权重之和，不包含现金；两者都空仓的日子未评价。增量对照为同伴百分位排名的固定等权融合与加入候选后的固定等权融合，两者均重新逐日模拟；融合要求共同有效样本。因此增量可能同时反映共同样本的变化，不能解释为纯粹信息贡献。未拟合最优权重。

## 评分

| 维度 | 权重 | 分项 |
|---|---:|---|
| 预测 | 25 | 主 Rank IC 10、Top-N 同池超额 10、分层相关 5 |
| 经济 | 25 | 扣费后基线超额 15、回撤和尾部 10 |
| 稳健 | 20 | 区间内分段 2、训练→验证 IC 3 / Top-N 1 / 基线超额 2、信号平滑 6、费用/延迟压力 6 |
| 实施 | 15 | 请求金额成交率 5、资金翻倍 5、成本后优势保留 5 |
| 增量 | 15 | 信号/收益/持仓重复度 5、固定组合加入效果 10 |

每项等级 0–4，得分=权重×等级/4；缺失为 null。所有阈值、实测值和解释保存于 `score.items`，网页逐条显示规则。基础规则：

- 信号统计：均值≤0 为0；均值正但HAC下界不正为1；下界正为3；再满足正值日≥60%为4。
- 经济超额：候选与基线年化收益率之差超过0、2、5、10个百分点分别累积1级。不是日超额收益的复利年化。
- 风险：先要求正基线超额；最大回撤、最差5%日均收益各不劣于基线得2级。
- 时间：按日历顺序四等分，每段有效IC数至少 `max(5,min_dates//4)`；均值IC正的段各1级。此项从8分降为2分，不替代训练—验证稳定性。
- 场景保留：候选年化收益必须正，场景年化收益/候选年化收益≥0、50%、75%、90%各1级。负收益情况下保留率无明确意义，记未评价。
- 成交：请求与成交数量都按各自前收估值，所有拒单仍计入分母；≥50%、75%、90%、98%各1级。存在无法估值请求则不评分。这是请求跟踪，不是目标组合跟踪误差。
- 重复：取同伴日信号绝对相关均值、绝对日收益相关、持仓交并比的最大值，低于95%、80%、60%、40%各1级；主IC非正为0。任一重复维度无足够数据则该项未评价。
- 增量：加入后年化改善>0、1、2.5、5个百分点各1级；最大回撤恶化超过2个百分点，最多1级。

默认显示“已评项目得分 / 已评权重”，例如 40 / 59，**不换算成满分100**。全100权重均有证据且不是合成数据才发布研究总分；80/65/50仅区分复核优先级。费用压力和成本保留共享证据，这种相关性明确保留为待校准权重，不能把各项当独立检验。分数也不跨不同市场、时间窗口、持有期直接排序。

## 证据、可比性与持久化

### 训练—验证稳定性（协议1.1新增）

`train_start`、`train_end`、`validation_start`、`validation_end` 四项须全空或全填，且训练结束严格早于验证开始。整体 Settings.start/end 须覆盖两段；不按结果自动选切分点。此处“训练”指研究参考窗口，系统没有自动拟合因子；即使填写了日期，仍不能证明此前未看过验证结果。

先比较训练与验证整体，再与每个验证年份比较；首尾年度按实际指定日期截取，页面保留请求日期、实际数据日期、有效样本数和边界剔除数。每一段的信号日和收益退出端点都须位于该段内。跨训练/验证、跨年度的标签各自剔除，gap 内不借用标签，缺失日期在HAC统计中保持原位置。

交易对照每段均独立从同样的 Settings.initial_cash 开始，不继承训练持仓，也不使用开始日前的信号下单；允许开始日前的历史行情参与因果特征预热。候选和基线复用同一交易设置，各自重跑。年初建仓费用会影响年度表现，各年结果不能拼接成整段验证收益；结束日仍按原引擎估值，不假设强制清仓。所有区间净值/日收益写入 evaluation_period_returns.csv。

对于“越大越好”的指标M，输出：变化=验证−训练、绝对差值=abs(变化)、退化=max(0,训练−验证)。最大回撤与尾部日均收益保留负数符号，数值更负代表风险恶化。只对Rank IC、Top-N超额、扣费后基线年化收益率之差计算保留率=验证/训练。默认训练参考下限分别为0.005、0.0001（单主期限收益）、0.01（年化收益率差），可在协议中预设；训练非正或低于下限时比值未定义，不给稳定性分。参考下限并非跨市场校准结果。

三个新增分项的等级规则相同：样本与覆盖须达标；验证值非正为0；验证为正且保留率≥25%、50%、75%、90%分别累计1级，改善不会扣分，等级上限4。验证均值的95% HAC下界不正时最多1级；训练均值下界不正时最多2级。IC和Top-N使用各自日度序列；年化基线超额的证据上限使用**日均扣费后基线超额**的HAC区间，不把它冒充年化收益率差的区间。年化超额分项另受风险上限约束：验证最大回撤恶化超过5个百分点，或最差5%日均收益恶化超过0.5个百分点，最多1级。不同区间长度会影响回撤和尾部估计，风险上限也是待校准的研究规则。

最终等级取验证整体与各验证年份的最低值；任一年度证据不足则该分项未评价，不能跳过低样本年份后宣称稳定。分别计IC保留3分、Top-N保留1分、基线超额保留2分，总计6分，原四等分时间项保留2分。未配置切分即缺这6分，完整场景测试也不能替代。训练IC 0.08下降到验证0.01，保留率12.5%，该分项为0级；训练和验证都接近零不因差值小获得高分。

均值差的95% HAC区间基于统一交易日轴上的两组中心残差：训练部分权重−1/n_train，验证部分+1/n_validation，各自做n/(n−1)小样本修正；采用Bartlett核，保留边界协方差与缺失/间隔日期。仅在两段均至少20个有效值时计算。年化收益、夏普、回撤及尾部差值不伪造解析置信区间。区间包含零**不能证明等效或稳定**；没有校正市场状态变化、试验选择或多重检验。评分阈值、真实观测和分年解释均保存于JSON及 evaluation_stability.csv。

`exploratory`、`declared_frozen_oos`、`declared_holdout`只是声明，`independently_verified`始终为 false。当前没有自动的预注册锁定、盲测访问隔离或实盘验证认证。合成数据明确标识且不发布总分。研究族和累计试验数随任务输入保存在本地数据库中，不能据此断言所有外部试验已登记。

完整协议 SHA-256 包含配置、声明、数据与规则摘要；额外的 `comparison_sha256` 仅排除研究族、试验数、证据声明，便于比较。有效行情矩阵另做内容哈希，即使内存输入没有供应商文件摘要也能区分。代码版本和源码包摘要仍在 report manifest 中，严谨比较还应核对代码摘要和数据规则版本。

新增文件：`evaluation.json`、`evaluation_daily.csv`、`evaluation_quantiles.csv`、`evaluation_yearly.csv`、`evaluation_scenarios.csv`、`evaluation_stability.csv`、`evaluation_period_returns.csv`。这些文件纳入不可覆盖报告目录、校验和、服务下载白名单；源码包包含评价模块。旧报告显示“未评价”，不会事后补造分数。

## 尚未解决的证据

行业/规模中性与风险归因需要历史时点数据；拥挤度、跨市场/状态的条件增量与尾部对冲贡献尚未实现。自动多重检验校正、DSR、PBO需要完整试验族和合法统计前提，当前不会用未知试验次数填默认值。实时paper追踪、参数邻域扫描、原始数据扰动和市场冲击函数也不在已实现证据内。

这些项目不得用现有高分替代。下一轮应先冻结评估任务与选择规则，在新的时间段校准阈值和权重，再讨论独立验证等级。当前后端和UI将缺口显式列出，避免把不完整的数据基础包装为“精准认证”。
